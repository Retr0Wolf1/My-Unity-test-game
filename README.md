# My basic game

## How to Run (VS Code ONLY)

1. Install [Visual Studio Code](https://code.visualstudio.com/)
2. Install **Live Server** extension (Extensions → search "Live Server" → Install)
3. Open game folder in VS Code
4. Right-click `index.html` → **Open with Live Server**

## Controls
- WASD - Move
- Space - Jump
- LMB - Shoot
